
## Inversiones

`src/api/investments.api.ts` implementa el comparador público y el seguimiento autenticado del cliente. El panel cooperativo administra productos, tasas vigentes y respuestas a solicitudes mediante `/api/credits/cooperative/me/investment-*`; no registra inversiones como solicitudes de crédito. La PII se comparte únicamente luego del consentimiento en la selección.
